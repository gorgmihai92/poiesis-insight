# Rethinking the Bounds of LLM Reasoning: Are Multi-Agent Discussions the Key? (Wang, Wang, Su, Tong & Song, 2024)

- **Source:** arXiv:2402.18272v1, 28 February 2024 · https://arxiv.org/abs/2402.18272 (a preprint)
- **File:** none (reference only)
- **Licence:** on arXiv; not checked.
- **Evidence:** empirical, as the abstract describes it.
- **Read:** abstract only, from the arXiv record · 2026-11-22

## What it says (from the abstract)
- A single agent with a strong prompt reached almost the same performance as the best discussion approach they tested, on a wide range of reasoning tasks and models.
- Discussion among agents did better than a single agent only when the prompt held no demonstration.
