# poiesis-insight

Insights, research questions and the methods of a field, from research or data: the `insight` skill picks a
playbook (insight, questions, methods, challenge); the agents `insight-analyst` and `challenger` run one part each, and every conclusion is challenged before it is reported. The verdict is recorded once, with a
stamp that other Poiesis plugins can verify. Foresight, which this plugin did until 1.4.3, is
[Poiesis Foresight](https://github.com/gorgmihai92/poiesis-foresight).

The plugin of [Poiesis Insight](https://github.com/gorgmihai92/poiesis-insight), one of the five products in the
Poiesis Toolkit: Research collects, Insight connects, Foresight anticipates, Frontier explores, Design creates
([Poiesis Research](https://github.com/gorgmihai92/poiesis-research), [Poiesis Foresight](https://github.com/gorgmihai92/poiesis-foresight), [Poiesis
Frontier](https://github.com/gorgmihai92/poiesis-frontier), [Poiesis
Design](https://github.com/gorgmihai92/poiesis-design)).

```
/plugin marketplace add gorgmihai92/poiesis-insight
/plugin install poiesis-insight@poiesis-insight
```
